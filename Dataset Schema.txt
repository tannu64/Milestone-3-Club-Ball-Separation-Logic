## Dataset Schema Analysis

### **1. Directory Schema**

#### **Naming Convention Pattern**
```
LOG[YYYYMMDD][HHMMSS]_B[BallSpeed]-H[Height]
```

**Components:**
- **LOG**: Fixed prefix indicating log file
- **YYYYMMDD**: Date in YYYY-MM-DD format (2024-01-28)
- **HHMMSS**: Time in 24-hour HH:MM:SS format
- **B[BallSpeed]**: Ball speed measurement (e.g., B97.9, B153.3)
- **H[Height]**: Height/launch angle measurement (e.g., H79.7, H101.9)

**Examples:**
- `LOG20240128164124_B97.9-H79.7` = January 28, 2024 at 16:41:24, Ball Speed 97.9, Height 79.7
- `LOG20240128171955_B153.3-H101.9` = January 28, 2024 at 17:19:55, Ball Speed 153.3, Height 101.9

### **2. File Schema**

#### **Binary Data Files (.bin)**
```
[DirectoryName]_[SequenceNumber].bin
```

**Naming Pattern:**
- **Single File**: `LOG20240128164124_00000000.bin`
- **Multiple Files**: `LOG20240128164124_00000000.bin`, `LOG20240128164124_00000001.bin`

**File Size Variations:**
- **Small Files**: 92KB - 500KB (single shots, quick recordings)
- **Medium Files**: 500KB - 1MB (standard shots)
- **Large Files**: 1MB - 1.7MB (extended recordings, multiple shots)

#### **Metadata Files (.json)**

### **4. Data Channel Schema**

#### **Signal Channels**
The dataset captures **4 intermediate frequency (IF) signals**:

1. **IF1 Upper**: First intermediate frequency, upper band
2. **IF1 Lower**: First intermediate frequency, lower band  
3. **IF2 Upper**: Second intermediate frequency, upper band
4. **IF2 Lower**: Second intermediate frequency, lower band

#### **Data Processing Parameters**
- **Sampling Rate**: 22,700 samples per second
- **FFT Window**: 1024-point Fast Fourier Transform
- **Data Step**: 64-sample increments for processing
- **Recording Mode**: Seamless (continuous data stream)
